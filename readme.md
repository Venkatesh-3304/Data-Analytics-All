
# 📊 Data Analytics – All

A single home for my hands-on practice across the core data analyst toolkit: **SQL, Excel, Power BI (DAX & Power Query) and Python**. It includes daily practice sets, assignments, mock-interview datasets, and an end-to-end HR Analytics dashboard project.

---

## 🧰 Tools & Skills

| Area | What I practiced |
|------|------------------|
| **SQL** | Joins, aggregations, filtering & sorting, subqueries, window functions, DDL, business-case analysis |
| **Excel** | Formulas, lookups (VLOOKUP/XLOOKUP/INDEX-MATCH), pivot tables, data validation, charts, dashboards |
| **Power BI** | DAX measures, Power Query transformations, interview prep |
| **Python** | Core fundamentals: variables, operators, strings, lists, tuples, sets, functions, loops, data structures |

## 🚀 Highlights

### 🗄️ SQL
- **14 days** of structured practice, each split by difficulty (Easy / Medium / Hard).
- **Retailmart Analysis**: revenue by category, top customers, monthly sales trends, and regional average order value.
- Quick-revision files for basics, DDL and aggregation, plus a **300-question interview PDF**.

### 📗 Excel
- Topic-wise assignments covering the full analyst workflow, from formulas to pivots to visualization.
- Interview-focused practice: **100+ questions**, 7 mock practice sets and an advanced mock.
- **HR Analytics Dashboard**: an Excel dashboard built on an HR dataset, with screenshots included in `Project3/Dashboard_Images`.

### 📈 Power BI
- DAX practice files (`.pbix`) with datasets for hands-on measures.
- 50-question DAX set and Power Query practice using a hotel dataset.

### 🐍 Python
- Jupyter notebooks covering Python fundamentals through functions and data structures.
- 40+ beginner exercises with solutions.

## ▶️ How to Use

1. **Clone the repo**
   ```bash
   git clone https://github.com/Venkatesh-3304/Data-Analytics-All.git
   ```
2. **SQL**: open `.sql` files in PostgreSQL / pgAdmin / DBeaver (queries use schema-qualified tables like `sales.orders`).
3. **Excel**: open `.xlsx` files in Microsoft Excel.
4. **Power BI**: open `.pbix` files in Power BI Desktop.
5. **Python**: run notebooks in Jupyter or Google Colab.
